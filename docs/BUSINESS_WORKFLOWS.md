# فرآیندهای کسب‌وکار کارخانه خوراک طیور (BUSINESS WORKFLOWS)

این سند فرآیندهای کاری واقعی کارخانه، مرغداران و رانندگان را ترسیم می‌کند که زیربنای معماری و منطق نرم‌افزار **NIRWARE NEXT** هستند.

---

## ۱. فرآیند جامع سفارش و تحویل دان (End-to-End Feed Order & Delivery Workflow)

این فرآیند قلب عملیاتی سیستم است و ذینفعان متعددی را به هم متصل می‌کند:

```text
  [ مرغدار ]
      │
      ├─ ۱. انتخاب گله فعال (Flock)
      ├─ ۲. مشاهده سهمیه مانده بر اساس سن گله (Quota Check)
      └─ ۳. ثبت درخواست دان (Create Feed Order) [DRAFT -> SUBMITTED]
             │
             ▼
  [ کارخانه: واحد فروش و مدیریت ]
      │
      ├─ ۴. بررسی اعتبار مالی و سهمیه مرغدار
      ├─ ۵. تأیید یا رد سفارش (Approve / Reject Order)
             │
             ▼
  [ کارخانه: واحد تولید و برنامه‌ریزی ]
      │
      ├─ ۶. بررسی موجودی دان آماده یا برنامه‌ریزی بچ تولیدی (Production Batch)
      ├─ ۷. آماده‌سازی پارت بارگیری (Order Ready)
             │
             ▼
  [ کارخانه: باسکول و لجستیک ]
      │
      ├─ ۸. تخصیص راننده و ناوگان (Assign Driver & Vehicle)
      ├─ ۹. توزین پر و خالی کامیون در باسکول کارخانه
      ├─ ۱۰. صدور حواله خروج رسمی با شماره بارنامه
             │
             ▼
  [ راننده: پرتال راننده ]
      │
      ├─ ۱۱. مشاهده سفارش تخصیص‌یافته و دریافت آدرس مرغداری
      ├─ ۱۲. تأیید بارگیری و شروع حمل (In Transit)
      ├─ ۱۳. تخلیه بار در سیلوی مرغداری
             │
             ▼
  [ مرغدار: پرتال مرغدار ]
      │
      ├─ ۱۴. تطبیق وزن و کیفیت بار تحویلی
      ├─ ۱۵. تأیید تحویل با امضای دیجیتال / کد OTP تحویل
             │
             ▼
  [ کارخانه: ثبت نهایی سیستم ]
      │
      ├─ ۱۶. ثبت سند خروج نهایی در دفترکل انبار (Inventory Ledger)
      ├─ ۱۷. کسر از سهمیه گله و افزودن به سوابق مصرف دان
      └─ ۱۸. ایجاد رکورد حسابداری (طلب از مرغدار / بستانکاری راننده)
```

### ماشین وضعیت سفارش دان (Order State Machine)
```text
DRAFT ──► SUBMITTED ──► PENDING_APPROVAL ──► APPROVED ──► PRODUCTION_PENDING
                                 │                │
                              REJECTED         CANCELLED
                                                  │
                                                  ▼
                                               READY
                                                  │
                                                  ▼
                                          ASSIGNED_TO_DRIVER
                                                  │
                                                  ▼
                                               PICKED_UP
                                                  │
                                                  ▼
                                              IN_TRANSIT
                                                  │
                                                  ▼
                                              DELIVERED
                                                  │
                                                  ▼
                                              CONFIRMED (FINAL)
```

## ۲. فرآیند ورود و خرید مواد اولیه (Raw Material Inbound & Weighing)

```text
  [ ورود کامیون حامل ذرت / کنجاله / مکمل به کارخانه ]
      │
      ▼
  [ باسکول کارخانه ]
      │
      ├─ ۱. ثبت بارنامه مبدأ (فروشنده، نوع کالا، وزن بارنامه، کرایه، مبدأ، راننده)
      ├─ ۲. توزین ناخالص (کامیون پر)
      ├─ ۳. ثبت تخلیه در سیلو / انبار مواد اولیه
      ├─ ۴. توزین خالص (کامیون خالی)
      ├─ ۵. محاسبه وزن خالص واقعی باسکول
      ├─ ۶. محاسبه خودکار افت بار (افت = وزن باسکول - وزن بارنامه)
      ├─ ۷. صدور قبض ورود با ۴ امضا
      └─ ۸. ثبت افزایش موجودی ماده اولیه در دفترکل انبار (PURCHASE ENTRY)
```

## ۳. فرآیند فرمولاسیون و تولید (Production & Raw Material Consumption)

```text
  [ کارشناس تغذیه / مدیر تولید ]
      │
      ├─ ۱. تعریف یا بازنگری فرمول دان (Formula BOM):
      │    - تعیین درصد اقلام (ذرت، سویا، روغن، مکمل و...) به گونه‌ای که جمع آنها دقیقاً ۱۰۰۰ کیلوگرم باشد.
      │
      ▼
  [ اپراتور بچینگ و تولید ]
      │
      ├─ ۲. انتخاب فرمول محصول نهایی (مثلاً میان‌دان گوشتی پلت)
      ├─ ۳. تعیین تناژ بچ تولیدی (مثلاً ۵ تن)
      ├─ ۴. بررسی موجودی مواد اولیه در انبار
      ├─ ۵. اجرای تولید و کسر خودکار مواد اولیه از انبار بر اساس نسبت فرمول
      ├─ ۶. افزایش محصول نهایی تولید شده در انبار
      └─ ۷. ثبت اتلاف و ضایعات تولید (Waste & Loss)
```

## ۴. فرآیند چرخه زیستی گله و پایش شاخص‌های عملکردی (Flock Lifecycle & KPI Monitoring)

```text
  [ مرغدار / کارشناس فارم ]
      │
      ├─ ۱. جوجه‌ریزی: ثبت تعداد قطعه، نژاد (راس، کاپ، آرین و...)، تاریخ شروع
      ├─ ۲. محاسبه جدول سهمیه پیشنهادی کارخانه بر اساس نژاد و سن
      ├─ ۳. ثبت روزانه اطلاعات گله (اختیاری یا منظم):
      │    - تلفات روزانه (Mortality)
      │    - مصرف روزانه دان (Daily Feed)
      │    - میانگین وزن هفتگی (Sample Weight)
      │    - مصرف آب و وضعیت محیطی
      ├─ ۴. پایش شاخص‌های کلیدی:
      │    - FCR (ضریب تبدیل غذایی)
      │    - درصد تلفات تجمعی (Cumulative Mortality %)
      │    - سرانه مصرف دان به ازای هر قطعه (Feed per Bird)
      └─ ۵. پایان دوره و کشتار:
           - ثبت وزن کل مرغ تحویلی به کشتارگاه
           - محاسبه FCR قطعی دوره
           - آرشیو دوره و صدور کارنامه نهایی
```

## ۵. فرآیند استخراج اسناد با هوش مصنوعی همراه با حلقه تایید انسانی (Human-in-the-Loop AI Extraction)

هوش مصنوعی هرگز نباید مستقیماً داده‌های حساس مالی و انبار را بدون نظارت کاربر وارد دیتابیس کند:

```text
  [ کاربر / مسئول باسکول ]
      │
      ├─ ۱. آپلود تصویر یا فایل PDF بارنامه / قبض باسکول
      │
      ▼
  [ موتور استخراج AI - Gemini Server-side ]
      │
      ├─ ۲. پردازش OCR و جداسازی هوشمند متون فارسی
      ├─ ۳. تفکیک قطعی نام فروشنده از نوع کالا (جلوگیری از ادغام مثل "احمدی ذرت")
      ├─ ۴. استخراج وزن بارنامه، وزن باسکول، شماره بارنامه، راننده، شبا و کرایه
      ├─ ۵. محاسبه نمره اطمینان (Confidence Score)
      │
      ▼
  [ پنجره پیش‌نمایش و بررسی انسانی (Review & Correction UI) ]
      │
      ├─ ۶. کاربر مقادیر استخراج شده را در جدول ویرایش‌پذیر مشاهده می‌کند
      ├─ ۷. اصلاح موارد احتمالی، انتخاب محصول مرتبط از لیست کارخانه
      └─ ۸. کلیک روی «تأیید نهایی و ثبت در سیستم»
             │
             ▼
  [ ذخیره‌سازی قطعی در دیتابیس ]
```
